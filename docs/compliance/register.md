# Security, privacy, integration and compliance register

No regulatory approval or production-security certification is claimed. This is a technical risk register, not legal advice or a completed legal review. Obtain qualified India/Kerala transport, privacy and payments review before commercial use.

| Area             | Current implementation                                                                | Release gate / owner                                                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Identity         | hashed random sessions, expiry, refresh rotation/reuse revocation, fixture OTP limits | approved OTP provider, new-user onboarding, verified consent text, abuse review / identity lead                                                             |
| Admin            | role/resource checks                                                                  | MFA/SSO, scoped staff permissions, audited provisioning / security lead                                                                                     |
| Tenant isolation | membership checks, cross-operator integration assertion                               | native DB/API penetration testing and RLS decision / security lead                                                                                          |
| GPS              | assigned active trips, freshness, accuracy/velocity validation                        | mobile background policy, purpose/retention approval, device lifecycle tests / mobile lead                                                                  |
| PII              | no raw tokens logged; inputs/errors redacted                                          | encrypted database/backups, access reviews, audit export, incident response / security lead                                                                 |
| Documents        | schema only                                                                           | private object store, short-lived signed URLs, MIME/size checks, malware scanning, review/expiry gates / onboarding lead                                    |
| Payments         | completed-trip cash record and immutable balanced ledger                              | approved Indian gateway, UPI requirements, signed webhook/replay validation, refunds/reconciliation/payouts / finance lead                                  |
| Transport        | route versions and dated services                                                     | current national/Kerala aggregator obligations, auto/taxi/share permits, fares, insurance, fitness and labour requirements / legal and operations           |
| Data protection  | consent records; pending export/deletion request records                              | applicability and review of Indian privacy law/rules, notices, rights fulfilment, grievance processes, lawful retention and vendor contracts / privacy lead |
| Safety           | bus stopped-use guidance                                                              | incident team, support/SOS/trip sharing, vetted drivers, escalation procedures / safety lead                                                                |
| Notifications    | opt-in service subscription and durable inbox                                         | FCM credentials, throttling, unsubscribe UI, anti-spam, delivery/retry/dead-letter handling / platform lead                                                 |
| Availability     | transaction/event atomicity, health/readiness, local tests                            | monitoring/trace instrumentation, native DB load test, backups/restore drill and UAT / SRE                                                                  |

Proposed development retention: worker deletes detailed GPS history after 24 hours, consumed refresh hashes after session expiry, OTP challenges one hour after expiry and expired rate windows after one day. These are engineering defaults requiring privacy/operations approval. Current locations, user records, financial records, audit rows and event/inbox retention require explicit production policies. Do not delete financial records to satisfy account deletion without legal analysis; pseudonymise through an approved workflow.

Account data requests are recorded as PENDING; they are not automatically fulfilled. No export is generated and no deletion is falsely reported. SOS is not wired to emergency authorities. Production startup refuses sandbox OTP; OTP provider, MFA, upload and payment integrations remain release blockers.
